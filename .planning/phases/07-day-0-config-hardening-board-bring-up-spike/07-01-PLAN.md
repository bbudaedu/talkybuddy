<objective>
結清 Day-0 零硬體風險的 config 與音訊技術債（EDGE-01）：
1. 把 server/llm.py 內硬編的 LLM context 視窗改為 profile-driven（edge=512、cloud/PC=1024，可 env 覆寫）。

依 spec-less probe，EDGE-01 目前為 unresolved edge（見 frontmatter assumptions），本 plan 以 5 條 success criteria 中的 #1/#2 具體化為可檢查 truths。
</objective>

## STRIDE Threat Register（ASVS L1，block on high）

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | pipeline RIFF-sniff / soundfile 解析 | medium | mitigate | header 只讀固定前 12 bytes 判 magic 後才交 soundfile；解析失敗走受控分支（ffmpeg fallback 或明確 raise），不讓未受信 bytes 造成未捕捉崩潰 |
