<objective>
把 llama-server 啟動參數（尤其 `--ctx-size`、`--host`、`--port`、`--threads`）的組裝邏輯，從「未來只寫在 shell 腳本字串拼接裡」改成一個獨立、純粹、可單元測試的 Python 函式 `build_llama_server_argv()`，並在 `server/config.py` 新增 llama-server 連線設定（host/port/threads），全部沿用既有 `TALKYBUDDY_*` env 慣例。

Purpose: `n_ctx`（context window）在 native `llama-server` 是啟動時 CLI flag（`--ctx-size`），不再是 `llama_cpp.Llama(n_ctx=...)` 建構參數。若只把它藏進 shell 字串，`config.LLM_N_CTX` 這個 profile-driven 值會失去自動化保護（Pitfall 2）。把 argv 組裝抽成純函式，才能讓 08-02 改寫後的 `tests/test_llm_n_ctx_profile.py` 斷言 `--ctx-size` 引數，維持與原測試等價的保護力；同時把「host 預設 127.0.0.1」寫進這個函式的預設值，作為 T-08-01（不對外暴露無驗證 LLM 端點）的結構性第一道防線。

Output: `server/config.py` 新增 3 個設定；`edge/runtime/run_llama_server.py`（含純函式 `build_llama_server_argv()` 與 `main()` launcher）；`tests/test_run_llama_server.py` 單元測試。
</objective>
